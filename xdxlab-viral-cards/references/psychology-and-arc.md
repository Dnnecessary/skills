# 心理触发器与情绪曲线：把"人性"用满

爆款的底层不是技巧，是**触发了某种人性**。`operation-engine.md` 里的三类选题（痛点 / 反常识 / 共鸣）是三个大入口，这份文件给更细的两件事：**触发器谱**（让人忍不住停下、看完、收藏、转发的具体心理扳机）和**情绪曲线**（一套图文怎么排出起伏，让人翻完还想转发）。

一套能打的内容，通常**叠加 2-3 个触发器**，并且**走一条有起伏的情绪线**——而不是平铺一堆信息卡。

---

## 心理触发器谱

每个触发器 = 一种让人产生动作的心理机制。下面每条给：机制、怎么用、真实例、要注意的度。

### 好奇缺口

- **机制**：信息只给一半，制造一个"非填上不可"的空缺。人对未完成的信息天生焦虑。
- **怎么用**：把最诱人的答案藏到后面，先抛悬念。「这 5 个里有 1 个是智商税，往后翻」。
- **度**：后面必须真的填上，且对得起吊的胃口，否则下次没人信你。

### 损失厌恶

- **机制**：怕亏、怕错过比"想得到"更能驱动行动。同样的事，说"会亏"比说"能赚"更戳。
- **怎么用**：把利益翻译成"不做会损失什么"。「房贷这样还，少还一辆车的钱」「现在不存，回头找都找不到」。
- **度**：损失要真实存在，别为了吓人编造后果，那是贩卖焦虑（见末尾"度"）。

### 身份认同

- **机制**：人会被"这说的就是我"击中，因为它确认了"我是谁/我属于哪群人"。
- **怎么用**：精准点名人群。「i 人社恐看过来」「南方回南天养猫的姐妹」「30+ 不想再讨好的人」。
- **度**：人群越具体越有效，但别贴负面标签骂用户。

### 优越感 / 谈资

- **机制**：转发能让人显得"我懂行、我有品、我先知道"。社交货币——分享是为了塑造自己的形象。
- **怎么用**：给读者"转出去有面子"的内容：冷知识、内行视角、小众好物、提前知道的消息。「内行才知道的 3 个细节」。
- **度**：内容真得有含量，不然转发的人会被打脸，等于坑了帮你传播的人。

### FOMO / 从众

- **机制**：别人都在用 / 都在做，我不能落下。社会认同——不确定时看别人怎么选。
- **怎么用**：呈现"大家都在……"的信号：热度、销量、真实人数、扎堆现象。「最近被问爆的那款」「评论区都在求的链接」。
- **度**：数字和热度必须真实，编造从众=造假，翻车最惨。

### 即时满足

- **机制**：明确、马上能拿到的回报，比模糊的长远好处更能让人停下、看完、收藏。
- **怎么用**：把收益说得具体、即时、低门槛。「照做今晚就能睡好」「3 步搞定，不用工具」。
- **度**：别承诺做不到的"立刻见效"。

### 窥私欲 / 真实感

- **机制**：人对别人的真实生活、账单、隐私细节有天然窥探欲。真实 > 精致。
- **怎么用**：晒真实——真实账单、真实房间、真实踩坑、第一人称糗事。粗糙但真实，比精致摆拍更抓人。
- **度**：晒的是自己的真实，别泄露他人隐私。

### 共情 / 情绪宣泄

- **机制**：把"想说但说不出口"的情绪替读者说出来，他获得被理解、被接住的释放感。
- **怎么用**：精准描述一种共同情绪，越具体越好。「和爸妈视频从来超不过 3 分钟」。靠的是评论和转发，不是收藏。
- **度**：共情不是卖惨，过度负能量会让人想逃离。

### 正义感 / 站队

- **机制**：内容帮读者表达了某个立场、对抗了某个对象，他通过点赞转发完成自我表达。
- **怎么用**：温和地亮明一个有共识基础的立场，给读者站队的机会。「这种套路真的该被拆穿」。
- **度**：对事不对人，别煽动人身攻击和群体对立，平台严打、也容易反噬。

### 互惠

- **机制**：你先免费给足价值，对方会产生"想回报"的心理（收藏、关注、评论）。
- **怎么用**：把干货给到"超出预期"，再自然提收藏/关注。「这套表我整理了俩晚上，免费拿去」。
- **度**：先给够，再要回报；上来就索取（关注才给）会劝退。

### 速查：触发器 → 主要服务哪层流量

| 触发器 | 最擅长拉动 |
|---|---|
| 好奇缺口 | 停留、完读 |
| 损失厌恶 | 点击、收藏 |
| 身份认同 | 点击、互动 |
| 优越感/谈资 | 转发 |
| FOMO/从众 | 点击 |
| 即时满足 | 收藏、完读 |
| 窥私欲/真实感 | 停留、完读 |
| 共情/宣泄 | 评论、转发 |
| 正义感/站队 | 评论、转发 |
| 互惠 | 收藏、关注 |

> 用法：先看这套内容**最想要什么结果**（涨粉看互惠+共鸣，带货看损失厌恶+即时满足，破圈看谈资+正义感），倒推该叠哪 2-3 个触发器，再落到选题角度和文案上。别一篇里硬塞五六个，会显得用力过猛、四不像。

### 伦理的度（红线，必须守）

触发器是用来**放大真实价值**的，不是用来制造虚假情绪的。三条红线：

- **不编造焦虑**：可以点出真实的痛，不能为了流量制造不存在的恐慌。
- **不制造对立到人身攻击**：可以有观点、可以站队，不能煽动群体互撕。
- **不虚假承诺**：钩子吊的胃口，后面要真的兑现。

这既是底线，**也是生意**：虚假的触发会被评论区拆穿、被平台限流、把账号做死。**你的长期利益和伦理在这里是一致的**——能持续涨粉的号，靠的是真东西。（标题层面的红线另见 `hook-and-title.md` 的"标题党的度"。）

## 情绪曲线 / 叙事弧

`operation-engine.md` 的完读设计解决"让人愿意翻"；情绪曲线解决"翻完愿意转发、记得住你"。一套图文不是一摞平铺的信息卡，是**一条有起伏的情绪线**。

### 峰终定律

人对一段体验的记忆，约等于**最高峰**那一下 + **结尾**那一下，中间会被大幅遗忘。所以一套图文必须刻意设计：

- **一个峰值页**：整套里情绪/信息最强的那一张，是你最想让人记住、最想被转发的内容。
- **一个有余味的结尾页**：不是干巴巴"谢谢观看"，是留一句有态度/有共情/有反差的话。

### 一条默认情绪弧

大多数选题可以套这条基本弧线，再按类型微调：

```
封面          张力钩子（勾住，先不给答案）
↓
痛点/共鸣页    把情绪拉下去（戳中"对这就是我"）
↓
转折页         "但是…/直到…"（事情有变化）
↓
干货/解法页    信息峰（给到真东西，最有价值的一两页）
↓
金句/反转页    情绪峰（最想被记住、被转发的一击）← 峰值页通常放这
↓
结尾页         余味 + 行动（一句有味道的话 + 一个互动 CTA）
```

### 几种常用弧型

- **先抑后扬**：痛点 → 解法 → 爽。干货 / 避坑 / 教程最稳的弧。
- **反转弧**：以为 A → 其实 B → 重建认知。反常识选题用。
- **共鸣递进**：一句比一句戳 → 结尾释怀或亮态度。情感选题用。
- **揭秘弧**：悬念层层加码 → 最后揭晓。故事 / 经历贴用。

### 峰值放哪、节奏怎么控

- **峰值别放第一页**：封面是"钩子"不是"峰"，太早把最猛的甩出来，后面就泄气了。把信息峰放中后段，情绪峰/金句放**倒数第二页**，最后一页收尾。
- **别全程平**：每页一样强 = 没有记忆点。要有起伏。
- **张弛交替**：一个信息密集的重页后面，给一个轻页（一句金句 / 大留白 / 一张图）让眼睛喘口气，再进下一个重页（配合 `content-planning.md` 的页面角色搭配）。
- **结尾留余味**：最后一句决定"转不转发、记不记得你"。落到一个具体动作、一句真心话、或一个反差收尾，别用空洞总结。

> 自检：给每一页的情绪强度打个分（1-5），连起来看——
> 1）是不是一条有起伏的线，而不是一条平的直线？平线就是没节奏，加入痛点低谷和金句高峰。
> 2）最高分那一页，是不是你最想让人记住、最想被转发的内容？不是就调整顺序或重写那一页。
> 3）最后一页有没有"余味"？读完想转发 / 想评论 / 记住了你，才算有；只是"总结一下"就是没有。
