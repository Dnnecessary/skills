# 风格体系 style-system

本文件定义 4 套小红书封面/版式风格的视觉法则。每套风格通过 `[data-style="<id>"]`
选择器覆盖 `base.css` 的 token（`--pad` / `--font-display` / `--font-body`）并新增风格化的类。
具体的色值与字号档位见 `style-presets.md`，两文件的 id 严格一致。

> 选风格的总原则：先看选题气质，再看人设调性。同一套图文里 4 套风格不混用。

| 风格 | id | 一句话气质 | 适用选题 |
|------|----|-----------|---------|
| 爆款原生 | `baokuan` | 大字报标题，色块砸脸，像素级生活感 | 干货 / 教程 / 种草 |
| 高级杂志 | `magazine` | 衡线留白，衬线优雅，编辑部出品 | 知识 / 深度 / 品牌号 |
| 柔和氛围 | `ambient` | 暖调奶油，呼吸感留白，温柔不喧哗 | 情感 / 生活 / 美妆 / 穿搭 |
| 极简冲击 | `minimal` | 单色背景，一句话顶满画面 | 观点 / 金句 / 态度 |

## 爆款原生 (baokuan)

**关键词**：大字报标题 + 高对比色块 + 手写感点缀 + 生活化质感。像朋友在你耳边喊"快看这个"。

**视觉法则**

- **字体选择倾向**：展示字用厚重无衬线黑体（粗到接近 Heavy / Black 字重），追求"墨更多"的视觉重量；正文用常规无衬线，保证密集信息也读得动。气质要"接地气"，不要冷淡极简。
- **版式骨架**：上部是占画面 40%–55% 的标题区，主标题拆成 2–3 行错落排布，关键词用色块底或描边框单独"圈出来"。中部放主体内容/步骤/清单。底部留一条带人设或引导的底栏。骨架可以略微不对齐、带一点倾斜或贴纸感，制造"随手做"的真实。
- **色块 / 留白 / 对比**：靠强对比驱动——浅底（奶油/米白）配一个高饱和但不刺眼的强调色（如暖橙、正红偏砖、克莱因蓝点缀），强调色用于关键词色块、序号圆点、下划波浪线。留白少而紧凑，信息密度高，但要靠色块分区避免糊成一团。
- **点缀元素**：手写感的圈划线、箭头、对勾、"!"、便利贴/胶带贴纸、序号大圆点、波浪下划线。点缀是这套风格的灵魂，但每张图控制在 2–3 个，多了就乱。

**适用选题**：干货合集、step-by-step 教程、好物种草、避坑清单、对比测评。

**识别测试**：缩略图状态下（看不清正文）仍能一眼读到一个被色块/描边"圈出来"的核心词，并感到"信息量很大、想点进去"——是。若标题秀气、留白克制、没有任何强调色块——不是。

**Anti-Pattern**：做歪成"廉价传单"——强调色用了纯红 #FF0000 这类刺眼原色、色块边缘生硬、贴纸点缀堆到 5 个以上、字体描边+阴影+渐变全上。爆款原生要的是"高级的热闹"，不是"五金店促销海报"。守住：强调色降一档饱和、点缀做减法、底色保持干净。

## 高级杂志 (magazine)

**关键词**：衡线（hairline）+ 大量留白 + 衬线字体 + 编辑设计感。像翻开一本纸质杂志的内页。

**视觉法则**

- **字体选择倾向**：展示字与正文都偏衬线（中文用宋体族），气质沉静、有文化感。可中英混排，英文用细衬线衬托标题。字重整体偏轻，靠字号与字距（letter-spacing）拉开层级，而非靠加粗。
- **版式骨架**：强网格感。顶部一条细发丝线 + 小字栏目标签（如 "ISSUE / 专栏名"）。标题区左对齐或居中，下方用发丝线分隔。正文走窄栏、行高宽松。页码、栏目名、日期等"刊物元数据"放在角落做点缀。大量上下留白，内容不必填满画面。
- **色块 / 留白 / 对比**：几乎不用色块，留白本身就是设计。对比来自"字号反差 + 细线分隔 + 黑白灰层次"。底色为纸白或极浅暖灰，主文字近黑（不用纯黑，用 #1a1a1a 一类），可有一个极克制的点缀色仅用于一条线或一个符号。
- **点缀元素**：发丝线（1px 细线，横/竖）、栏目标签小字、页码、引号、序号用罗马数字或细体阿拉伯数字。一切点缀都"安静"。

**适用选题**：知识科普、深度长文导读、行业观察、品牌/主理人调性号、书影音推荐。

**识别测试**：遮住所有文字内容，是否仍能凭"细线分隔 + 大留白 + 网格秩序"看出这是一页有编辑感的杂志版式？是。若靠色块或大字才撑得起画面——不是。

**Anti-Pattern**：做歪成"空洞的 PPT 模板"——留白变成"没东西可放"的尴尬空，发丝线画太多变成表格，衬线字配了居中+斜体+大字距显得做作。高级杂志的留白是"自信的克制"，不是"内容不够"。守住：每页有明确的视觉焦点、细线只在需要分隔时出现、字距适度。

## 柔和氛围 (ambient)

**关键词**：暖调 / 莫兰迪色系 + 大面积留白 + 柔和字体。像清晨的暖光，温柔不喧哗。

**视觉法则**

- **字体选择倾向**：展示字用圆润或细秀的字体（细黑体或轻量圆体），正文用常规无衬线但字重偏轻。整体气质柔软、亲切、没有攻击性。可适度用大字距营造松弛感。
- **版式骨架**：松散、呼吸感强。元素居中或偏置都行，但彼此间距大、不挤。常用"一张大留白底 + 一句轻标题 + 一段短文案"的极简结构，或配一块柔和色卡/圆角图片。底栏轻盈，常只放一个小署名。骨架不强调网格秩序，强调"舒服的随意"。
- **色块 / 留白 / 对比**：核心是低饱和暖色系——奶油白、燕麦、浅陶土、雾霾蓝绿、藕粉等莫兰迪色。对比刻意压低，文字色不用纯黑而用暖棕灰（如 #5b5048），让整体"糊得温柔"。大面积留白，色块以柔和圆角色卡形式出现，绝不用硬边高饱和。
- **点缀元素**：圆角色卡、细小的圆点、柔和的引导小字、极淡的分隔线。一切边缘都"软"，多用圆角（较大 radius）。

**适用选题**：情感随笔、生活方式记录、美妆护肤、穿搭、家居、慢生活。

**识别测试**：眯起眼睛只看色彩与明暗，是否给人"暖、柔、低对比、想深呼吸"的感觉，而非"清晰锐利"？是。若出现纯黑文字、硬边色块或高饱和色——不是。

**Anti-Pattern**：做歪成"灰扑扑没重点"——所有元素一样轻、一样灰，整页找不到落点；或莫兰迪色调错成"脏色"（饱和度压过头显得发污）。柔和不等于没层级。守住：仍要有一个最重的视觉焦点（哪怕只是稍深的标题），莫兰迪色保持"低饱和但干净"。

## 极简冲击 (minimal)

**关键词**：单色背景 + 超大字 + 一句话冲击力。整张图就是一句话，重重砸下来。

**视觉法则**

- **字体选择倾向**：展示字用极粗或极有态度的无衬线黑体，字号超大（占满画面宽度）。一般只有一种字体、一种字重撑全场。正文/注脚极少，只做主句的"垫脚"。
- **版式骨架**：极简到只剩一句话。主句通常 4–12 字，拆成 2–4 行垂直堆叠，顶满安全区。无多余装饰、无图片、无清单。可在角落放一个极小的署名或一句注脚作为重量配平。骨架就是"一句话 + 大量同色背景"。
- **色块 / 留白 / 对比**：背景是单一纯色（不一定是白——可以是深墨、克莱因蓝、暖陶土等有态度的单色），文字用与背景强对比的单色（深底浅字 / 浅底深字）。不用第二种色块。留白由超大字自然挤出，不是刻意排布。对比拉到最满。
- **点缀元素**：几乎没有。最多一个标点的放大（一个超大的"？"或"。"）、一条短下划线、或一个极小角标。点缀越少越对。

**适用选题**：观点输出、金句、态度宣言、扎心文案、立 flag。

**识别测试**：遮住文字内容（只看版式骨架与配色），是否仍一眼看出"这是一句话海报"——满屏一种背景色、文字占据绝对主体、没有任何清单或图片？是。若有第二个色块、有清单、有配图——不是。

**Anti-Pattern**：做歪成"放大版爆款原生"——加了强调色块、加了贴纸点缀、加了第二句解释。一旦开始"补充信息"，冲击力就泄了。守住：一句话就是一句话，克制住"想多说一点"的冲动；背景纯到底，对比拉到满。
