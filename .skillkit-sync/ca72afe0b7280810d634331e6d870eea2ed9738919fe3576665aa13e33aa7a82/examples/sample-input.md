# 第一次养猫，这些坑我全踩过了

去年十月把猫接回家之前，我以为养猫就是"买个猫粮、买个猫砂盆"的事，结果开学一样的学费交了一遍。写下来给同样要新手上路的人提个醒。

第一个坑是猫砂。我图便宜买了一种粉尘很大的矿物砂，猫一上厕所家里就跟下了层雾一样，猫自己打喷嚏，我也开始过敏。换成豆腐砂之后基本没尘，结块也清楚，铲屎一目了然。早知道直接买贵一点的，省下来的医药费比差价多多了。

第二个坑是猫粮换得太急。接回家当天我就把猫粮全换成了我精心研究的"高蛋白无谷粮"，结果猫吐了两次，拉稀拉了三天，去医院开了一堆药。后来才知道换粮要七天以上慢慢过渡，每天混入比例一点点增加，肠胃才受得了。这事我是真没想到，看着说明书才后悔。

第三个坑是磨爪子。我家沙发角被啃得不成样子，那时候才想起来要买猫抓板。其实猫天生就要磨爪，不给它一个能磨的地方，它就会自己找——而且大概率找你最贵的那件家具。提前买好猫抓板、猫抓柱，摆在它常待的地方，能省掉很多家具维修费。

第四个坑是疫苗和驱虫的时间表。我一开始完全没规划，等到猫已经半岁了才想起来打疫苗，结果免疫程序乱了，还得重新做一遍。建议接回家第一周就去医院做个体检，顺便让医生给你排好疫苗和驱虫的时间表，照着打就行，不用自己瞎猜。

第五个坑是猫砂盆的位置和数量。我一开始只放了一个砂盆，还放在洗衣机旁边，猫嫌吵根本不愿意进去，结果在角落里尿了好几次。后来按"猫的数量+1"的原则放了两个砂盆，分散在安静的角落，猫才正常使用。

第六个是关于陪伴时间的误区。我以为猫很独立,不用怎么管,结果我加班晚归的那段时间,猫开始抓沙发、半夜叫、不爱吃饭。后来每天固定花十几分钟陪它玩逗猫棒,这些行为基本都消失了。猫比想象中需要陪伴,只是表达方式不一样。

这几条都是真金白银和半夜挂急诊换来的经验，希望能帮第一次养猫的人少走点弯路。如果你也有踩过的坑，欢迎在评论区补充，我整理一下出个二期。
