# 字体与质感：拉高"好看"的天花板

排版骨架决定"对不对"，**字体和质感决定"高不高级"**。同样的版式，换一套展示字体、加一层细腻质感，观感能差一个档次。这份文件讲两件事：用什么字体、怎么加质感。

---

## 为什么不能只用系统字

系统默认字体（PingFang / 微软雅黑）是安全牌，但**它也是"默认感"的来源**——读者天天看见，用它做标题，第一眼就透着"随手做的"。真正出彩的小红书封面，展示字体（标题那几个大字）几乎都用了有个性的字体。所以：

- **正文**可以用系统字（清晰、稳，不抢戏）。
- **展示标题**尽量上有辨识度的展示字体，这是性价比最高的一次升级。

---

## 已内置：得意黑 Smiley Sans

本 Skill 已附带**得意黑**（`assets/fonts/SmileySans-Oblique.woff2`，免费商用），在 `base.css` 里用 `@font-face` 注册为 `"Smiley Sans"`。它自带利落的倾斜，是大字报/海报/态度向标题的利器，已默认接入 **baokuan** 和 **minimal** 两套风格的 `--font-display`。

调用方式（已在预设里配好，自定义时照此写，**务必保留中文兜底**）：

```css
--font-display: "Smiley Sans", "PingFang SC", "Microsoft YaHei", sans-serif;
```

> 注意：得意黑只有一个倾斜字重，适合"冲击力/有态度"的标题；安静、文艺、克制的内容（magazine / ambient）不要硬套它，会显得用力过猛。

## 按风格的字体倾向

| 风格 | 展示字体倾向 | 当前用法 |
|---|---|---|
| baokuan 爆款原生 | 厚重 / 有冲劲的黑体 | 得意黑（已内置）|
| minimal 极简冲击 | 极粗 / 有态度的黑体 | 得意黑（已内置）|
| magazine 高级杂志 | 衬线（宋/明体）撑文化感 | 系统 Songti SC（够用）；想更讲究可上思源宋体 |
| ambient 柔和氛围 | 轻字重黑体 或 楷体 | 系统 PingFang 轻字重；想更柔可上霞鹜文楷 |

## 更多可选免费商用字体

需要更强的视觉差异化时，下载下面这些**免费商用**字体到 `assets/fonts/`，再用 `@font-face` 注册即可（中文字体文件大，优先用 `.woff2`）：

- **霞鹜文楷 LXGW WenKai**：柔和手写感楷体，极适合 ambient / 文艺 / 情感选题。
- **思源宋体 Source Han Serif / 思源黑体 Source Han Sans**：工业级标准字族，多字重，宋体撑 magazine、黑体 Heavy 撑 minimal 大字。
- **站酷系列（站酷高端黑 / 快乐体 / 庆科黄油体等）**：各有个性，适合特定调性封面。
- **得意黑 Smiley Sans**：已内置。

获取与接入步骤：

1. 找到该字体的官方发布页（GitHub Releases / 官网），下载 `.woff2`（没有就下 `.ttf/.otf`，体积更大）。
2. 放进 `assets/fonts/`。
3. 在 `base.css` 里加一段 `@font-face`：

```css
@font-face {
  font-family: "LXGW WenKai";
  src: url("fonts/LXGWWenKai-Regular.woff2") format("woff2");
  font-display: swap;
}
```

4. 在对应风格的 `--font-display` 里把它放在最前，后面跟中文系统字兜底。
5. 复制到任务目录时，记得把 `fonts/` 一起带上（见 `production-workflow.md`）。

> 红线：只用**明确标注个人+商用免费**的字体。方正、汉仪等多数商用字库需授权，不要用在可能商用的账号内容里，避免侵权。拿不准就用已内置的得意黑 + 系统字。

## 质感层：从"平涂"到"有材质"

纯色平涂干净，但容易显得平、像 PPT。加一层克制的质感，观感立刻"贵"起来。`base.css` 已提供基础能力：

- **全局细噪点**：`.poster::after` 已默认给每张图叠一层极淡颗粒（`soft-light` 混合），在亮底/暗底上都能制造纸感/胶片感，不伤可读性。无需手动开启。
- **暗角 `.tex-vignette`**：四周轻微压暗、聚焦中心，给**深色背景**（minimal）加纵深。在 `.poster` 上加这个类，或直接写 `box-shadow: inset 0 0 240px rgba(0,0,0,.4)`。
- **柔投影 `--shadow-soft`**：给卡片/图位用的柔和阴影（`box-shadow: var(--shadow-soft)`），是 magazine / ambient 的高级感来源——区别于 baokuan 那种硬朗的实心偏移投影。
- **光晕 / 渐变**：在 `.poster` 的 `background` 上叠 `radial-gradient` / `linear-gradient`，作为背景绘制，永远在内容之下。例如暖调晨光：

```css
background:
  radial-gradient(55% 40% at 82% 10%, rgba(255,246,235,.85), transparent 70%),
  var(--bg);
```

### 质感的"度"

质感是用来"托"内容的，不是用来抢戏的。守住三条：

- **噪点要细要淡**：看得出"有质地"，但说不清"哪里有颗粒"。一眼就看到噪点 = 太重。
- **渐变要平要缓**：同色系微过渡（如奶白→奶米），制造光感即可；撞色大渐变会显廉价、像早期 PPT。
- **投影要软要浅**：高级感的投影是"几乎看不见但东西浮起来了"。又黑又硬的大投影是廉价感重灾区（baokuan 的硬投影是风格化的故意为之，别和柔投影混用）。

> 自检：把质感层全关掉对比一眼——加上之后如果你的第一反应是"咦哪里不一样了但就是更舒服了"，就对了；如果第一反应是"这个噪点/渐变/阴影好明显"，就是过了，调淡。
