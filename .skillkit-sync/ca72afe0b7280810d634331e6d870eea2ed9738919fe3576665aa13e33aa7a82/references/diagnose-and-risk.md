# 数据复盘与风控：让爆款可复制、别被限流

爆款不是玄学，是迭代出来的。这份文件两件事：发布后**看数据找病因**（让下一篇更好），和发布前**过一遍风控**（别辛苦做完却被限流）。

---

## 数据复盘诊断

小红书后台能看到一套漏斗数据，每个指标对应漏斗的一层。**别看总数据，要看哪一层在漏人**——病因不同，改法完全不同。

**怎么开始复盘（输入）**：平台没有开放接口，读不了用户后台，只能让用户提供。一次性问齐：①后台数据（截图最省事，能直接读图；或文字报数），指标带全——曝光量、点击率/封面打开率、完读率/人均阅读时长、互动（赞/藏/评/转）、新增关注；②笔记本身（封面+内容页截图，至少封面），没有它只能给通用建议；③可选：选题、标题、话题、发布时间。诊断流程（定位漏斗层→结合实际内容找具体病因→改法→可选重做）见 SKILL.md 的「复盘模式」。

### 核心指标 = 漏斗的每一层

- **曝光量**：系统推给了多少人。低 → 选题/标签/限流问题（内容还没被看到）。
- **点击率（封面打开率）**：看到的人里多少点进来。低 → 封面问题。
- **完读率**：点进来的人里多少翻到底。低 → 内容/节奏问题。
- **互动率（赞 / 藏 / 评 / 转）**：看完的人里多少动手。低 → 钩子/CTA 问题。
- **涨粉数**：互动的人里多少关注。低 → 人设/系列问题。

### 诊断对照表

| 数据表现 | 病因 | 改法 |
|---|---|---|
| 曝光一直很低（几百就停）| 选题没需求 / 标签不对 / 触发了限流 | 换选题角度（回 `operation-engine.md` 选题自检）；查违禁词（见下）；补精准关键词和话题 |
| 曝光正常，但点击率低 | 封面没抓住人 | 重做封面：换更强的钩子、加大对比度、缩短标题（`cover-design.md` + `hook-and-title.md`）|
| 点击率高，完读率低 | 首屏没接住 / 中间垮了 / 信息过载 | 首屏立刻兑现封面承诺；按情绪曲线重排节奏；每页减负（`psychology-and-arc.md`）|
| 完读率高，互动低 | 没给互动的理由 | 加评论钩子、收藏理由、结尾单一 CTA（`operation-engine.md` 互动引导 + `caption-and-comments.md`）|
| 数据都不错，就是不涨粉 | 只有"这一篇"的价值，没有"这个号"的理由 | 补人设信号、系列预告、关注钩子（`account-persona.md`）|
| 数据忽高忽低、不稳定 | 选题/风格漂移，账号没有稳定标签 | 收敛到固定领域和主风格，做系列（`account-persona.md`）|

### 迭代心法

- **一次只改一个变量**：这篇换了封面，就别同时换选题和风格，否则数据变了你也不知道是谁的功劳。
- **同选题 A/B 试**：同一个内容做两版封面/两个标题，看哪个点击率高，把赢的那套沉淀成模板。
- **爆了要拆解、扑了也要拆解**：爆款拆"它戳中了哪个触发器、封面强在哪"，复制到下一篇；扑街的对照上表找到漏的那一层，单点修。

> 复盘自检：打开一篇的数据，先问"漏斗哪一层最低？"，只针对那一层改。别看到数据差就把整篇推倒重做——那样学不到任何可复制的经验。

## 风控 / 限流自查

限流是涨粉最大的隐形杀手——内容没问题，却因为踩了平台红线，曝光被悄悄掐掉，你还以为是内容不行。出图和写文案时过一遍下面几类。

### 违禁词 / 极限词

- **绝对化用语**：「最」「第一」「顶级」「国家级」「100%」「绝对」——《广告法》敏感词，平台会限流。换成「我用过最满意的之一」「个人觉得很顶」这类有主观限定的说法。
- **虚假/夸大承诺**：「包瘦」「根治」「稳赚」「三天见效」——尤其医疗、金融、美妆功效，碰不得。

### 导流 / 外链

- 正文/图上**留微信号、QQ、其他平台账号、具体购买链接、二维码** → 直接限流甚至违规。
- 引导私下交易、"加我领"这类导流话术也算。需要引导时用平台允许的方式（评论区互动、主页）。

### 搬运 / 侵权

- 非原创、带其他平台水印、盗用他人图片/文案 → 判搬运，限流或下架。
- 配图用图库/网图时注意版权（见 `image-handling.md`），字体用免费商用（见 `typography-and-texture.md`）。

### 敏感领域合规雷区

- **医疗 / 医美 / 减肥 / 金融理财 / 代购**：功效宣称、收益承诺、处方建议、跨境代购都是高危区，轻则限流重则封号。这类内容只讲个人体验、不做功效/收益承诺、不指导用药用资。

### 蹭热点的边界

- 不蹭悲剧、灾难、政治敏感事件博流量——既违规又招骂（详见 `trendjacking.md`）。

### 出图前风控清单

- [ ] 标题/封面/正文有没有绝对化、极限词、虚假承诺？
- [ ] 图上或正文有没有微信/二维码/外链/其他平台账号？
- [ ] 配图、字体、文案是不是原创或已获授权、无他站水印？
- [ ] 如果是医疗/医美/减肥/金融/代购类，有没有越界做功效或收益承诺？
- [ ] 数字、事实、价格是不是真实、可核实（不伪造，时间按北京时间）？

> 任意一条不过，先改再发。被限流一次，这篇基本就废了，重发也救不回——风控是发布前的事，不是事后补救的事。
