# 配图处理：截图、选图、压字、裁切

图文里的图片处理不到位，是最容易暴露"这是批量生成的"的地方——拉伸变形的截图、压暗到看不清的背景图、3:4 裁切切掉主体的人脸,都会让整套图文显得粗糙。这份文件给出截图处理、选图原则、压字安全区、裁切取值四块的具体操作方法。

---

## 截图处理

截图是可信度最强的素材之一（参见 `operation-engine.md` 里"选题自检清单"的"可信度支撑"），但截图本身的画幅通常和 3:4 画布不一致，处理不好就会显得突兀。

- **目标比例画布**：所有 `.poster` 都是 1080×1440（3:4）。截图原图大多是手机截屏（9:16 或更长），直接塞进 3:4 容器一定会被裁切或拉伸，处理前先想清楚截图里"必须保留的区域"在哪。
- **安全留白**：截图放进卡片时，四周留出与正文留白呼应的边距（不要让截图直接顶到画布边缘，除非是有意做"出血"效果的大图配方）。截图本身如果带有系统状态栏、无关的导航栏，优先裁掉这些区域,只保留信息本体。
- **不拉伸截图**：永远使用 `object-fit: cover`（配合 `object-position` 控制裁切位置，见下文），绝不用 `object-fit: fill` 或直接拉伸宽高比——拉伸会让文字变形、界面比例失真，一眼能看出是"硬塞进去的"。
- **清晰度优先**：截图是这一页的证据，证据必须看得清。如果截图里有重要信息（数据、聊天内容、对比结果），优先把截图本身放大、占据更多画布面积,周边的说明文字相应缩小、简化为一行注脚,而不是把截图缩小去给大段文字让位。判断标准："这一页如果只看截图,能不能看懂要点"——能,说明截图够大;不能,放大它。

## 配图选图：怎么选不像 AI

读者对"AI 生成感"的图片越来越敏感，一旦封面或内文图让人觉得"这是 AI 画的"，可信度会直接打折。选图时按下面的优先级走：

**第一优先：用户提供的真实照片/截图**

如果素材里有用户自己拍的实物图、生活场景图、App 截图、聊天记录截图，**永远优先用这些**。真实素材自带"这是真人在分享"的信任感，是最不像 AI 的图片来源，也是最强的可信度证据。即使画质一般、构图不完美，也通常比一张精致但空洞的 AI 图更可信。

**第二优先：图库照片**

没有真实素材时,选有真实拍摄痕迹的图库照片（自然光、真实场景、不过分摆拍）。避免选那些"一看就是商业图库"的过度精致、过度摆拍、笑容僵硬的图——这类图本身就带"广告感"，和 AI 生成图一样容易让人划走。

**最后选项：AI 生成图**

只有在真实素材和图库都没有合适选择时才用 AI 生成。生成时注意：

- **role-specific（角色明确）**：生成图要对应这一页具体要表达的内容（比如"一个人在出租屋里挂窗帘的背影"），不要生成泛泛的"风格氛围图"，否则图和文字脱节,读者会觉得"这张图随便放的"。
- **无内嵌文字/logo**：AI 生成图里经常会出现乱码文字、变形的 logo、不存在的品牌标识——这些是最明显的"AI 痕迹"，生成后逐张检查，有就换图或裁掉对应区域。
- 生成图尽量作为**背景/氛围**使用（比如图片打底式封面的底图），不要作为"证据"使用——证据类的角色（截图证据、数据强调）必须用真实素材，AI 图撑不起可信度。

## 文字压在图上的安全区

把标题、要点文字直接压在照片上时（图片打底式封面、大图+说明等配方），最容易出的问题是**文字和背景搅在一起看不清**。处理顺序是：

**第一步：选图时就考虑文字区**

挑图的时候，优先选画面里本身就有一块"安静区"（天空、墙面、桌面留白、纯色背景）的照片，把标题规划放在这块区域。这样不需要任何后处理，文字天然清晰——这是成本最低、效果最好的方案，**永远优先尝试**。

**第二步：选不到干净安静区时，加局部蒙版**

如果照片整体细节都很多、找不到安静区，给文字所在的那一小块区域加一个**局部渐变蒙版**或半透明色块（比如标题区下方加一个从透明到半透明深色的渐变），只覆盖文字背后的区域，不影响照片其他部分的呈现。

**第三步：调整图片自身的明暗/色调**

如果蒙版还不够，可以对整张图做轻微的滤镜调整（稍微降低对比度、整体调暗一档），让图片作为"背景"更安静，但调整幅度要小——目标是图片退后给文字让路，不是让图片变得看不清内容。

**不要做的事**：默认给整张图盖一层大面积黑色蒙版"以防万一"。这是最偷懒也最破坏体验的做法——读者点进来是想看图，整图压暗会让配图形同虚设，也会让封面/内容页显得"廉价"。蒙版应该是**局部的、有目的的**，覆盖范围只到文字需要的地方。

> 自检顺序：先问"这张图本身有没有安静区可以放文字"——有就直接用；没有就问"加一块局部蒙版能不能解决"——能就只加局部;局部蒙版也不够再考虑调整图片整体色调。三步走完还不行，说明这张图不适合压字，换图。

## object-position 裁切守则

所有图片配方都使用 `object-fit: cover`，这意味着图片会被裁切以填满容器——裁切位置由 `object-position` 决定。**每张图都要按它的主体位置内联设置 `object-position`**，绝不能全套图统一用默认的 `center center`，否则在 3:4 竖向画布里很容易把人脸、产品主体、关键文字裁掉。

设置方法：先看这张图的主体在画面里的大致位置（人脸在上半部分？产品在画面中间偏左？风景图的地平线在哪一档？），再按下表给出参考取值：

| 场景 | 建议 `object-position` | 说明 |
|---|---|---|
| 人像/人脸为主体 | `center 15%` ~ `center 25%` | 人脸通常在画面上半部分，3:4 裁切时容易被切掉头部，往上偏移保留人脸 |
| 产品/实物特写 | `center center` ~ `center 40%` | 产品通常居中，视情况略微上移给标题留出底部空间 |
| 室内场景/家居改造图 | `center 30%` ~ `center 40%` | 保留墙面和主要家具，避免裁到地面占比过大 |
| App 截图/聊天记录 | `center top` | 截图的关键信息（标题栏、第一条消息）通常在顶部，裁切时优先保留上部 |
| 风景/氛围图作背景 | `center center` 或按地平线调整 | 地平线高的图往下偏移（如 `center 60%`），地平线低的图往上偏移（如 `center 30%`） |
| 横向长图被裁成竖向 | 先确定主体在横图中的左右位置，对应设置 `left center` / `right center` / `center center` | 横图裁竖图丢失面积最大，主体不在中间时必须手动指定左右位置 |

> 操作流程：每张图放进配方前，先粗略看一眼主体大致在画面的哪个区域（上/中/下，左/中/右），按上表给一个初始值，渲染截图后检查这张图在 1080×1440 画布里主体是否完整可见——被裁掉就调整百分比再重渲染。不要图省事全部留空或全部用 `center`，那等于把裁切交给运气。
