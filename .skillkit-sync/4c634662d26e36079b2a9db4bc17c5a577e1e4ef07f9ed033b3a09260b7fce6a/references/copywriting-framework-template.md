## 9. 发布前检查清单

- [ ] 标题是否明确包含对象、变化或读者收益？
- [ ] 开头是否快速说明读者为什么值得继续读？
- [ ] 核心判断是否有事实、案例或数据支持？
- [ ] 正文结构是否与选题类型匹配？
- [ ] 是否明确适用对象、限制和风险？
- [ ] 是否区分原文证据、抽象模板和结构化示例？
- [ ] CTA 是否与正文承诺一致且不过度诱导？
- [ ] 是否检查原创性、引用和事实准确性？

## 10. 禁用边界

- 不复制原文连续表达。
- 不冒充原作者身份。
- 不照搬独特经历、私密故事或未公开素材。
- 不输出与样本事实冲突的案例。
