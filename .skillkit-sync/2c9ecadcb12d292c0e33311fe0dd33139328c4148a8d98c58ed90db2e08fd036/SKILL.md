# 墨青测评风公众号排版 Skill

将 Markdown、纯文本、Word、PDF 或已有正文整理为可直接粘贴到微信公众号编辑器的 HTML。**本技能只支持墨青测评风（`ink-teal-tech`）**；不存在主题选择、主题混搭、通用组件库、主题生成器或其他主题的回退路径。

唯一视觉依据是：

- `assets/theme-previews/ink-teal-tech-component-showcase.html`：**正式组件全集与用户确认的母版清单**。母版中作为排版组件展示的项目均视为已确认的正式组件，必须纳入本技能的骨架或资产、调用条件、内容路由与校验；不得自行降级为“仅展示”或排除。母版中的说明文字、颜色样本、浏览器外框等展板 UI 不属于文章组件。
- `references/ink-component-library.md`：**组件骨架单一来源**。从完整母版、同作者原作与用户确认的新增项提取组件真实 HTML 骨架、真实频率与触发条件。取组件骨架一律先查此文件。
- `references/theme-ink-teal-tech.md`：母版白名单、完整组件骨架、触发条件、封面与词内动画规则。
- `references/ink-teal-source-evidence.md`：`wechat-article_ink-teal-before-full-cover.html` 母版与五篇同作者文章的可追溯证据。
- `references/format-normalize.md`：非 Markdown 输入的结构化转换规则。

## 核心原则

1. **母版优先、组件调用为默认且强制**：任何文章排版都只能调用用户已有组件；结构、标签、胶囊、分隔符、END、媒体容器、IP 与介绍语等均不得现场手写近似版、重绘、改造组件文件或另存文章专用组件。组件资产只在用户明确要求“维护/修改组件”时才允许动。
2. **唯一创作例外是语义场景动画**：文章内容需要表达具体动作时，可按该处语义自行绘制场景动画；这只允许新增动画内容，不得借机改写周边组件、全局样式、组件骨架、IP/介绍语、胶囊、分隔符或其他已有资产。封面外壳、左侧 IP 和介绍语均调用既有完整封面组件；仅当用户明确要求更换封面语义场景时，才可在不改组件外壳及固定组件的前提下替换中段场景。
3. **母版白名单与内容结构判定**：完整母版中已确认的正式排版组件全部属于技能白名单。排版时根据文章内容结构和真实素材判断触发，不要求 Markdown 预先写出英文标签；不满足该组件明确条件时才回落正文。
3. **正文优先**：找不到白名单组件时，回落为 2.1 正文段落与 4.3 E1–E7 行内强调。不得借用引用块、金句卡、提示卡、参数卡、数据表、流程图、作者签名区或 CTA。
4. **真实媒体优先**：窗口式图片卡只承载用户提供的真实产品 UI、过程截图或结果截图；没有真实图片时不伪造图片、图注、流程图或数据卡。
5. **母版动效不可降级**：封面是固定 IP + 中央介绍态/场景态的 SVG SMIL；正文可演出的词必须是同一个 inline SVG 内“字形 path ↔ 手绘场景 path”的交叉动画，不能替换为普通静态标签或独立动图。
6. **保留原文语义**：原文已有的加粗、编号、图片、说明、列表与结尾标记不随意改写；`**【素材精粹】**` 等字段标签保持加粗，不得误改为浅绿底 E7。

## 唯一工作流

### 1. 归一化输入

- Markdown 直接进入结构识别。
- `.docx`、`.pdf`、纯文本或富文本先读 `references/format-normalize.md`，只整理结构，不改写原意。
- 输入不完整、媒体来源不清或无法判断结构时，先明确风险；不得虚构图片、数据或案例。

### 2. 读取唯一规则库与来源证据

每次排版必须读取：

1. `references/ink-component-library.md`（组件骨架单一来源）；
2. `references/theme-ink-teal-tech.md`；
3. `references/ink-teal-source-evidence.md`；
4. 当前文章本身。

不读取、不引用、不恢复 `common-components.md`、其他 `theme-*.md`、主题索引候选、文章类型配方或主题生成器。

### 3. 先做文章分析，再建立内容路由表

**这是不可跳过的前置阶段，不是排版前的预判。** 先完整读取当前文章及其真实媒体，分析其叙事结构、同级单元、先后关系、已有强调、标题层级与媒体关系；再逐单元匹配组件。不得在分析完成前预先声明“本篇只使用 / 不使用某些组件”，也不得因为文章表面上有编号、案例、更多、步骤等字眼直接选组件。

每篇必须先形成可审计的文章级路由表，至少逐项记录：

1. 当前文章的主线结构与每个内容单元；
2. 真实媒体清单及其与正文的关系；
3. 每个候选正式组件的结论：调用时写明对应的原作调用模式与当前同构证据；不调用时写明不满足哪一项原作结构；
4. 回落为正文、行内强调或真实媒体的内容范围。

只有路由表完成后，才能确定本篇实际组件组合并进入 HTML 排版。组件选择必须是该次分析的结果，不能写成先验限制。

**禁止绕过技能路由。** 不得为单篇文章新建、修改、运行或复用“专用装配脚本”“文章配方脚本”“正则批量替换脚本”来生成正文 HTML，也不得以这类脚本预先决定组件组合。单篇正文必须直接依照本技能的组件库、原作调用谱、主题规则和上述路由表逐段装配。`component_lint.py`、`validate_gzh_html.py`、`wrap_preview.py` 仅可用于技能规定的校验与预览，不属于正文装配路径。

先读 `ink-teal-source-evidence.md` 的「原作调用谱」：**原作调用模式**是规则来源，描述作者把组件置于何种叙事位置、承接何种内容；**路由最低条件**仅是排版器避免误套的执行约束，绝不表述成作者明文规范。当前内容无法确认与任一原作模式同构时，回落正文与真实媒体。

逐个内容单元按以下顺序判断，不能跳步：

1. 是否为标题：生成 3.1 的封面场景动画。
2. 是否复刻 A4 的单一方法流程：步骤顺序不可互换、每步推进同一工作流、总数在原文明确给出时，用 2.2 `STEP n/m`；`n/m` 必须来自原文。
3. 是否复刻 A1–A6 的测试序列：前文已交代同一产品/工具的测试目标，当前单元是一项可独立讲清的实测任务，后面承接过程、真实媒体或结果时，用 2.3 `CASE` 胶囊；不要把步骤、能力总览或补充亮点改成 CASE。
4. 是否复刻 A3 的主项目分段：围绕同一项目推进多个叙事大段，每段具有独立主题和连续内容时，用 2.16 `PART`。多个分段是排版器的识别防线，不是作者明文数量规则。
5. 是否复刻 A3 的产品能力总览：产品总览后先集中列出“能力标题 + 短解释”，随后才进入实测或项目时，用 2.3b 纯文字胶囊 `POINT`（C3，**无 SVG 图标**）；纯同级章节用 2.3 深色图标胶囊裸 `01/02/03`（C2）；母版中的明确彩蛋追加用 `BONUS`（C2）。标签必须来自相应原作或母版结构，不能混用，也不能给 POINT 补图标。
6. 是否复刻 A5 的收纳结构：主 CASE 或主论证结束后、总结与 END 之前，存在同一主题的“其他亮点 / 补充发现”组时，用 2.17 `MORE`；不得拿总结、目录、延伸阅读或普通补充句冒充 MORE。
7. 是否有真实 UI/过程截图、视觉成片或原图：按 2.4 / 2.5 选媒体容器；按 A5/A6 的同一成果连续页或同一对象多状态证据使用 2.10 `GALLERY`，按 A6 的分段演示媒体组使用 2.11 内容标题轨，按 A6 的同一对象静帧+实机对照使用 2.13 `STILL/GIF`，按 A6 的“媒体上沿自定义对象名”使用 2.14 tab。按 A4 的“问题 → 连续 SHOT → FINAL CUT → 差异解释”结构使用 2.18 `STORYBOARD / SHOT`；连续镜头媒体是最低识别条件，不是作者明文规则。原样呈现真题/模考作文题用 2.15「真题呈现」块（标签固定，标题按联考/模考名填写，要求句灰色）；图注必须来自原文或材料。
8. 是否为原文明确要求圈出的重点词：才可用 2.8 静态圈注词，全文最多三处。
9. 是否为无标题承接的真实正文话题转折且需要一次呼吸停顿：才可用 2.9 三方块分隔符，全文最多两处；不得作为章节标题、媒体或 `/// END` 前后的间隔。
10. 是否自然收束且适合使用母版结尾组件：可用 2.7 动画像素 `/// END`；不要求 Markdown 预先包含 END 标签。
11. 是否存在真实录屏/过程录像：用 2.13a `REC` 标明素材状态；静帧与动态实机的成对对照用 2.13 `STILL/GIF`，二者不可混用。
12. 原文附大段可复制提示词/代码且确有滚动结构：用 2.12 `PROMPT` 块（Prompt 回落正文的唯一例外）；其他全部使用 2.1 正文段落和 4.3 行内强调。

明确禁用：目录、引言卡、尾部签名区、数据/参数卡、表格、流程图、引用块、金句卡、提示卡，以及任何白名单外容器。`PART`、`MORE`、`STORYBOARD / SHOT` 均为条件自动路由组件，必须满足各自结构条件，不得仅为丰富版式套用。

`HEADS UP` 提示块（2.6）为白名单内条件组件：仅当原文确有明确的风险、限制、前提或避坑信息时启用，骨架取自主版参考页；一般提醒/注意事项仍回落 2.1 正文，不能因为「有提醒」就自动套用。

### 4. 装配正文

- 全局容器、正文段落、颜色、间距、字体和图片骨架直接取自主题规则库，不手写近似版本。
- 普通叙述型长段落（至少 40 字）必须有 1–2 处 E1–E7 行内强调；样式必须逐字照抄主题 4.3，不得组合、改色或自造。
- 每篇先形成“段落 → 强调短语 → E 编号”的审计清单；没有清单不得交付。
- 只要使用词内场景动画，审计表必须另列：`原文完整句子 → 动画原词（逐字）→ 场景主体/动作 → 首帧原词可读 → 场景态可辨认 → 复位帧原词可读`；任一栏未验证，不得交付该动画。
- 动词/具象名词动画按主题 3.2 生成：字形与场景在同一个 SVG 内互补切换；**动画绑定的原词必须先从原文逐字摘录并写入审计表**，字形层只画该原词，不能误替换为相邻名词、删字或改字。首帧、场景退场帧和循环复位帧都必须完整显示同一原词，且字形层与场景层的 opacity/keyTimes 无空档、无同屏残影；只在场景播放窗口隐藏字形。场景必须与实际动画词一一对应，画面在手机宽度下能辨认物件与动作；生物/人物等具象主体须保留比例合理的完整可识别结构（例如鸟须有头、喙、躯干、尾羽与连续双翼，并表现对应动作），不得仅用字形 path、V 字、弧线或抽象符号充当场景。任一项不通过时，取消该动画并回落为普通正文强调；静态圈注词不进入动画层。
- 深色图标胶囊按 C2 选取与标题语义相符的原作 14×14 图标；同篇多个章节不得机械复用一个图标，除非内容语义确实重复。无法找到合适图标时，改用已验证的无图标编号样式。
- 封面按主题 3.1：`1246×220`、左侧固定毕业女孩纯 path IP、固定点阵介绍语及其镜面倒影/飞散复位、不使用 SVG `<image>`/`<text>`/`foreignObject>`、场景遵循同一空间中同一对象 `S0 → S1 → S2` 的连续事件。封面场景必须有手机端可辨认的主体与可见动作，不能退化为几条弧线、空框或简笔符号。**左侧毕业女孩 IP 与介绍语/倒影是独立的既有组件：文章排版只能原样调用 `user-graduate-girl-cover-pixel.svg` 和 `cover-intro-groups.xml` 的已验证内容，不得在单篇文章或封面装配中手写、重绘、重排、改色、改坐标、改时序或替换其任何路径。** 封面整体直接从 `assets/theme-assets/ink-teal-tech/cover-scene-animation.html` 唯一完整组件调用；如某一场景组件已存在，只能选择并调用，不得为当前文章现场改造该资产。组件本身只有在用户明确要求维护组件库时才能修改，且修改对象必须先经过用户确认。文章与资产的封面内容须逐字节一致；不得用箭头、流程图、标签或氛围特效替代事件。
- 任何可见中文文本均用 `<span leaf="">` 包裹；所有样式内联；遵守公众号平台红线。

### 5. 生成预览与校验

输出前必须依次执行：

```bash
python3 scripts/component_lint.py .
python3 scripts/validate_gzh_html.py --theme ink-teal-tech <output.html>
python3 scripts/wrap_preview.py <output.html>
```

- `component_lint.py` 必须 0 ERROR。
- `validate_gzh_html.py --theme ink-teal-tech` 必须 0 ERROR。
- E4、E5、E6 的母版渐变告警属于已知例外，但必须逐项确认它们确为白名单样式；不得为消除告警改变母版。
- 对封面至少检查介绍态、每个关键场景态、恢复态及固定 390px 容器；SMIL 逐帧检查用 `pauseAnimations()` 与 `setCurrentTime(t)`，不能依赖浏览器虚拟时间。

### 6. 输出

1. 交付干净的 `<section>...</section>` 正文片段，不包裹 `<!DOCTYPE>`、`<html>`、`<head>` 或 `<body>`。
2. 文件名使用 `{原文件名}_排版_墨青测评风(ink-teal-tech).html`。
3. 同时交付 `wrap_preview.py` 生成的预览页；复制按钮不应位于被复制的正文 `section` 内。
4. 交付说明必须包含：使用的白名单组件、强调审计结果、校验结论、渐变告警（如有）、以及未验证的风险。

## 平台红线

禁止 `<style>`、`<script>`、`<div>`、`class`、`id`、`position:fixed/absolute/sticky`、`float`、`@media`、`@keyframes`、`display:grid`、CSS 变量与外部字体。允许内联 style、`section`、`p`、`span`、`strong`、`img`、`svg` 与 SMIL 动画。

## 维护规则

- 新规则必须先在母版或同作者成品中找到逐字节证据，写入 `references/ink-teal-source-evidence.md`，并得到用户确认后才能进入 `theme-ink-teal-tech.md`。
- 不得把其他主题的经验、组件或语义映射加回本技能。
- 不得删除或替换主题 IP、封面生成器、圈注/字形生成器，除非用户明确要求并完成对应视觉验收。
