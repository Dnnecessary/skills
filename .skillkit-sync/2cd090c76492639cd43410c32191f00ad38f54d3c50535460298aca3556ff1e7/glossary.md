# 术语表

> 按拼音排序。括号为所在章节。

- **报告与意见** — 报告只据实陈述人事物，任何人说结果相同；意见是作者自己的主张，换个人说未必如此。读文章要分清哪些是报告、哪些是意见（Ch01）。
- **辨证（辩证）** — 推理方式之三，正题—反题—合题的推进（Ch08）。
- **材料** — 题材所包含的事项；取舍标准由文章的"意味"决定（Ch02）。
- **测定（判别）** — 材料的筛选判断，以文章意味为准（Ch02）。
- **触发** — 由一事物联想到另一事物、由此及彼的思维契机（《文心》第十三节，Ch10）。
- **辞的认识** — 对词语（辞）的意义、用法的认识（《文心》第十一节，Ch10）。
- **倒错** — 叙述时不按时间顺序，而作倒叙、插叙等安排（Ch02）。
- **演绎** — 由一般到个别的推理方式（Ch08）。
- **归纳** — 由个别到一般的推理方式（Ch08）。
- **感觉与印象** — 描写即记印象；景物描写写"我"的印象而非客观清单（Ch04）。
- **风格** — 一篇文章与别人同类作品相异的独特之处（Ch01）。
- **含蓄与暗示** — 不直说本意，而借相关事物使人意会（Ch04）。
- **心中的"意味"（文章意味）** — 文章给读者的新知识、新情味、新教训，决定材料的判别取舍（Ch02）。
- **鉴赏与批评** — 说出文章好坏以及好在哪里、坏在哪里（Ch01、Ch17）。
- **命题与主旨** — 议论文所要证明的中心主张（Ch07）。
- **篇章（章法布局）** — 文章从开端到结尾的脉络、主干与旁枝（Ch01）。
- **普遍性** — 个别事物所体现的共同道理；鉴赏由个别上升到普遍（《认真阅读》，Ch17）。
- **情味** — 文章给予读者的情感意味，与知识、教训并列为三种意味之一（Ch02）。
- **取景与观点** — 叙述时观察的立足点，要求一致，移动须交代（Ch03）。
- **人称立脚点** — 第一、第二、第三人称各自的立足点与适用场合（Ch03）。
- **散文与韵文** — 文章两大类别，按有无押韵节奏区分（Ch04）。
- **真切经验与浮浅幻想之辨** — 文艺须以真切人生经验为骨子，否则为浮浅幻想（《认真阅读》，Ch17）。
- **生活是写作的好材料** — 写作素材来自实际生活经验（Ch13）。
- **思想与语言** — 思想是"不出声的语言"，语言是"出声的思想"，二者二而一（Ch13）。
- **通与不通** — 文章是否意思连贯、合乎语言习惯（Ch16）。
- **文心（读写的故事）** — 以故事体裁讲国文知识的写法，将读法与作法、教与学打成一片（Ch09-Ch12）。
- **文艺鉴赏** — 不止被动感动，而要主动研究考察"为什么感动""是否最有效"，须说得出好在哪里（Ch17）。
- **问题指导** — 略读/精读中带着问题去读的指导方式（Ch18、Ch19）。
- **习作** — 凭各人的底子，努力说好话并写出来；即练习说话、练习思想，是实际生活而非假设游戏（Ch13）。
- **修词（修辞）** — 对同一意思采用不同说法以求特定效力（Ch01）。
- **序目指导** — 读书先看序目提要，把握全书大意的指导方式（Ch19）。
- **选材** — 依文章意味从题材中选取适宜材料（Ch02）。
- **训练语感** — 培养对词语分寸、声调语气的敏感，为鉴赏与应用打底（Ch18）。
- **版本指导** — 略读时选择适当版本的指导方式（Ch19）。
- **描写** — 把作者的印象写出，令读者如见其事（Ch04）。
- **描写与记叙** — 叙述事情经过为记叙，刻画印象为描写，二者常结合（Ch04）。
- **意味三性质** — 新知识、新情味、新教训（Ch02）。
- **想象（驱遣）** — 借想象把文字还原为具体情境，读懂作品（Ch18）。
- **写话** — 写作如同说话，怎么说就怎么写，求其自然真切（Ch13、Ch14）。
- **形式探究七项** — 体制、语汇、文法、修辞、鉴赏批评、风格、章法布局（Ch01）。
- **应用文** — 书信、报告书、说明书等日常生活实用的文体（Ch01、Ch05）。
- **语体文** — 以现代口语为基础的文体， vs 文言体（Ch01）。
- **语汇与语感** — 词语的积累与对语言的敏感（《文心》第十七节，Ch11）。
- **议论文变装** — 议论主张隐藏在叙事抒情之中、不易察觉的形态（Ch07）。
- **上口与入耳** — 文章念起来顺口、听起来顺耳，是修改的重要标准（Ch16）。
- **精读** — 通读全文、认识生字生语、解答问题三步骤的深入阅读（Ch18）。
- **略读** — 抓大意、广涉猎的阅读，含版本、序目、参考书、方法、问题五项指导（Ch19）。
- **主旨** — 文章的中心意思，议论文尤其要明确（Ch07）。
- **题材** — 作者认为有新的意味的事物，是材料的来源（Ch02）。
- **知识** — 文章给予读者的三种意味之一，指新的认识（Ch02）。
- **直接经验与间接经验** — 亲身经历为直接经验，他人/书本所得为间接经验；间接经验须证明其可靠（Ch03）。
- **揣摩** — 反复玩味关键语句的所以然以求深入领会（Ch18）。
