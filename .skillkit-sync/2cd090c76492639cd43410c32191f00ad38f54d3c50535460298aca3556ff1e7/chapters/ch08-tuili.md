# Chapter 8: 推理方式

## Core Idea
议论文是推理的记录；从理由到达判断的推理有演绎、归纳、辩证三种方式——演绎从普遍到个别，归纳从个别到普遍，辩证则把事物当流动变化、互相联系的东西来看。

## 框架与概念
- **推理与议论文**：从理由到达判断的作用叫推理；议论文可以说就是推理的记录。
  - 何时用：检验一篇议论文是否站得住时。
  - 怎么做：看其判断以什么理由为根据、从理由到判断是否合于推理的方法与规则。
- **演绎法（三段论法）**：以既知的普遍判断为基础，应用到个别事物而造出新判断。
  - 何时用：把一般原理应用于个别事物时。
  - 怎么做：由大前提（凡甲是乙）、小前提（丙是甲）、断案（故丙是乙）三命题合成；如"凡人都是要死的／圣人是人／故圣人是要死的"。实际文章中常颠倒或省略，检查时应补足成完整式样。
- **形式论理的三规律**：演绎只论概念不究实质，故又名形式论理。
  - 何时用：检查演绎推理的正确性时。
  - 怎么做：①同一律——"甲是甲，不是乙或丙"，一个名词只许表示一种事物、不许歧义；②矛盾律——"甲不是非甲"，既肯定是什么就不能同时否定说非什么；③排中律——只许说"甲是乙"或"甲非乙"，不许有中立判断。同一律最基本，其余二者是补充。
- **归纳法**：以个别的事物为根据，得到较普遍的判断，可补演绎的不足。
  - 何时用：演绎的大前提有疑问、须证明它时。
  - 怎么做：从各种事物观察归纳出普遍判断（"凡生物是要死的"）；归纳所得的判断是否正确，也须演绎地应用到个别事物去考查（如发现鸡鸭桃柳中有不死的，判断即不能成立）。
- **归纳的两规律**：判断可靠的条件。
  - 何时用：评估归纳判断是否坚固时。
  - 怎么做：①部分现象的搜集须普遍而且没有反例；②现象和判断之间有明确的因果关系。满足一种即可认为正确；下判断时因果关系的存在与发见比现象搜集更重要。
- **辩证法**：重视实际条件、不把事物用单纯概念来处理的推理方式。
  - 何时用：判断事物的"有用/有害"等须视具体情形而定的问题时。
  - 怎么做：把事物当作动的、连续的、进展的东西，并把转变流动的实际情形当作条件（如"金钱有用还是有害"要看分量、所有者态度手腕、使用方法及社会情形而定）。
- **辩证法的三原则**：为便于说明而立，非推理的定律或公式。
  - 何时用：理解事物发展进步时。
  - 怎么做：①矛盾对立——以矛盾为出发点（生长与死亡、作用与反作用、正与负）；②量影响到质——量的改变使性质变化（水百度成汽、零度成冰；一元纸币积贮成资本）；③否定的否定——事物发展取否定之否定顺序，又叫"正反合"（谷子→禾→新谷），是进步的根源。

## 关键概念
- **大前提 / 小前提 / 断案**：三段论法的三个命题。
- **三段论法**：演绎推理的基本形式，由三个命题合成。
- **同一律 / 矛盾律 / 排中律**：形式论理的三个基本规律。
- **形式论理**：演绎只论概念、不究实质，故名。
- **归纳法**：从个别到普遍的推理，补演绎之不足。
- **因果关系**：归纳判断中比现象搜集更重要的可靠条件。
- **辩证法 / 正反合**：重视实际条件、把事物当流动进展的推理方式与原则。

## 心智模型
- 当把一般原理用于个别事例时，用演绎法，并补足成三段论检查其正确。
- 当普遍判断本身可疑时，用归纳法从个别事物建立它，再演绎地应用检验。
- 当判断"某物有用还是有害"时，用辩证眼光把它放在具体条件中，而非抽象断言。
- 把同一律理解为"名词不得歧义"：定义不清，一切辩论都是白费。

## 反模式
- **演绎只论概念不究实质、名词歧义**：如"书"可指书籍或《书经》，双方解释不同则言语白费。
- **归纳缺乏反例检查或因果不明**：判断动摇、不可靠。
- **以偶发反例推翻有明确因果的判断**：如个别乡村住民比都市住民敏捷，不能推翻"都市住民比乡村住民敏捷"。
- **抽象断言"金钱有用/有害"**：不顾分量、态度、方法与社会情形，与实际大不符，等于议论游戏。
- **抛开实践专套辩证原则**：结果会犯堕入空虚概念的毛病。

## 文中实例
演绎的三段论："凡人都是要死的"（大前提，凡甲是乙）、"圣人是人"（小前提，丙是甲）、"故圣人是要死的"（断案，故丙是乙）。只要大前提、小前提不错，断案当然成立。实际说话作文中常省略为"圣人是要死的，因为他是人"或"凡人是要死的，故圣人要死"，但检查议论正确与否时，最好补足成完整式样。

## 关键要点
1. 议论文是推理的记录；判断须以理由为根据。
2. 演绎由大前提、小前提、断案构成，遵守同一律、矛盾律、排中律。
3. 归纳从个别到普遍，可补演绎不足，其可靠靠无反例与明确因果。
4. 因果关系比现象搜集更重要，偶有反例不足推翻有因果的判断。
5. 辩证把事物当流动、联系、进展的东西，重视实际条件。
6. 辩证三原则——矛盾对立、量变影响质、否定之否定（正反合）是说明的方便，非公式。
7. 三法各有所宜：演绎求形式正确、归纳求经验可靠、辩证求切合实际。
