# Chapter 14: 审题与选题

## Core Idea
题目与文字都生根于自己的意思情感——"先有了意思情感才有题目"。挑题要挑了解得确切、感受得深刻、自己能写的；动笔前必须"想清楚然后写"，并在实际生活里把观察、推理、语言习惯的功夫做在"拿起笔来之前"。

## 框架与概念
- **诚实的自己的话**：写自己"必要说的与欢喜说的话"，尺度是"这文字里的表白与感兴是否确实是作者自己的"。
  - 何时用：判断一段文字是不是"自己的东西"时。
  - 怎么做：有内面的根源才写；不因模仿而勉强，不为利用而写作。"写出自己的东西并不是"说人家没说过的话——通用的言词也可用，关键是内面根源独立。
- **求诚**：原料要真实深厚，不说不可征验、浮游无着的话；写作要诚恳严肃，不取油滑、轻薄、卑鄙的态度。虚伪、浮夸、玩戏都与之相反。
  - 何时用：检验文字是否"美好"时。
  - 怎么做：表白合于事理真际、切乎生活实况；感兴本于内心郁积、发乎情性自然。
- **挑能写的题目**：某个题目值得写是一回事，"我能不能写"又是一回事；辨别标准是"了解得比较确切，感受得比较深刻"。
  - 何时用：面对值得写但未必能写的题材时。
  - 怎么做：非了解确切不写，非感受深刻不写；做不到就"暂且把笔放下"，去考察、去体验，有了了解感受再写。
- **想清楚然后写**：动笔前把"为什么写、该怎样写、哪些必要写、哪些用不着写、哪些在前在后、有无缺漏、读者是否够明白"都解答确切。
  - 何时用：每次提笔之前。
  - 怎么做：抓住关键"为什么要写"这个根；先写提纲（或腹稿），提纲越详细，写成整篇越容易。
- **题目生根于意思情感**：题目是意思情感的中心写成的简约文字；"没有根，那悬空无着的题目从何而来呢？"
  - 何时用：思索题目与文章的先后关系时。
  - 怎么做：先有意思情感再标题目；教师出题也要设身处地，唤起学生固有的意思情感，才不违反自然程序。
- **拿起笔来之前的准备功夫**：文章难不难"决定在动笔以前的准备功夫怎么样"，最重要的是实际生活习惯：精密观察、仔细认识、有条有理地推理下判断、正确的语言习惯。
  - 何时用：觉得"拿起笔样样从头做起"很难时。
  - 怎么做：平时养成习惯——语言跟心思一致（不走样）、按约定俗成（不违背规律）；"实际生活充实了，写文章就会像活水那样自然地流"。

## 关键概念
- **内面的根源**：写这篇文、说这席话自有独立的根源，即使与别人雷同也不算模仿。
- **实习/练习**：每一回动笔都有练习性质，谁也不敢说从内容到一词一句全无懈可击。
- **腹稿**：写在心头的详细提纲，"详细的提纲就跟成篇的东西相差不远"。
- **语汇**：在心里是意念单位，在语言里是构成语句的单位；要孤立地了解，更要从例句、从近似语汇比较中了解。
- **语法**：语句构造的方法，无非约定俗成；"吃饭"不能说"饭吃"，"我佩服你"不能说"你佩服我"。
- **约定俗成**：语言规律的实质——"语言好比通货，不能各人发各人的"，必须大家公认才有价值。
- **作自己要作的题目**：除教师命题外，自己有意思情感就动手写，把作文与生活结合。
- **提纲**：把中心、材料、次序预先列出，是"想清楚"的外化。

## 心智模型
- 当遇到一个"值得写"的题目时，先问自己"了解得确切吗、感受得深刻吗"，而不是提笔就写。
- 把"题目"理解为"意思情感的标签"，没有意思情感这个根，题目就是悬空的。
- 当写不出来时，把原因归到"没想清楚"或"平时功夫不到"，而不是"没有材料"——经验就是材料。
- 把"句式"理解为可变换的工具：一句不通，就换一种样式试，直到与上下文适合为止。

## 反模式
- **存利用的心思去写**：自己无可写而采取人家资料，或无意为模仿却"复制了人家现成的东西"——一用"自己的表白与感兴"尺度衡量即败露。
- **以朦胧印象为满足**：自以为想清楚其实没想清楚，边写边想；已成之局难大改，又急着拿出去，结果自己不满意、人家看不明。
- **题目越出经验范围**：如《师严而后道尊说》《学而时习之论》，学生"想胡说也无从说起"，逼得虚构或交白卷。
- **设定字数下限**："内容少，几十字也无妨"，先规定至少数百字会错过许多片段感兴的习作机会。
- **写日记公式**："昨日晨起夜眠，进三餐，上五课，皆如前日"——不曾反省或懒于动笔，把日记写成刻板账。
- **临渴掘井**：平时心粗气浮、语汇认不清、语法拿不稳，临到写作才想精密观察，成就必然有限。

## 文中实例
作者举"挑能写的题目"两例：创制、改良新农具是值得写的题，但若对构造、原理、效用"似懂非懂"，一支笔就像干枯的泉源渗不出一滴水；参加修建十三陵水库义务劳动也是值得写的题，但若除"热烈""伟大""紧张"之外没有真切感受，专用形容词怎能成篇？办法是"暂且把笔放下"，再去考察农具的实际情形，再去工地好好劳动几天，有了了解和感受自然能写。这印证：非了解确切、非感受深刻不写，练习一回有一回长进。

## 关键要点
1. 用"是否真是自己的表白与感兴"作尺子，拒绝模仿与勉强。
2. 求诚：原料真实深厚，态度诚恳严肃，力戒虚伪、浮夸、玩戏。
3. 选题先问"能不能写"——了解确切、感受深刻才动笔，否则先去补课。
4. 认定"先有意思情感才有题目"，多作自己要作的题目，把作文变成生活的一部分。
5. 养成"想清楚然后写"的习惯，抓住"为什么写"这个根，先列提纲或腹稿。
6. 把准备功夫做在平时：精密观察、有条有理地推理、正确的语言习惯（语汇与语法）。
7. 教师命题也应站在学生立场，不出超越经验范围的题。
