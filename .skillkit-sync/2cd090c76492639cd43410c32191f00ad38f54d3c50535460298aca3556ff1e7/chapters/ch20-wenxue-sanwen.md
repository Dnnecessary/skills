# Chapter 20: 散文与写人——名篇里的鉴赏眼光

## Core Idea
叶圣陶选散文、讲散文，核心是教青年辨明「主脑」与「多余的文句」：好文章必从真实生活流出，剪裁到「说话要没有多余的话，作文要没有多余的文句」。读散文不是记零碎事情，而是读出灌注全篇的那一点情与所写人物的性格。

## 框架与概念
- **主脑**：一篇文章的中心，全部材料都须与它发生关系才写。如《背影》以父亲的背影为主脑，「凡是和父亲的背影没有关系的事情都不用写；凡是要写出来的事情都和父亲的背影有关系」。
  - 何时用：读一篇记人记事文，判断某段材料该不该写时。
  - 怎么做：先找出主脑；游逛等一笔带过的事即因与主脑无关；再由主脑定剪裁，读后才不算「白读」。
- **主旨**：全文要传出的那一点意思；「读一篇文章，如果不明白它的主旨，而只知道一点零零碎碎的事情，那就等于白读」。
  - 何时用：读完一篇散文自问收获时。
  - 怎么做：《背影》的主旨即从背影传出父亲爱惜儿子的一段深情；把零碎事情归结到这一句。
- **实写 / 虚写**：叙述动作外貌是实写，作者从眼睛看出的心理是虚写。如「扑扑衣上的泥土」是实写，加一句「心里很轻松似的」是虚写。
  - 何时用：描写人物动作、要使读者「宛如看见」时。
  - 怎么做：实写为主，偶用一语虚写衬托；这一语「把父亲情愿去做这一番艰难工作的心情完全点明白了」。
- **画一圈界线**：写眼睛看见的光景（速写），须在种种光景里画一圈界线，要写的圈进来，用不着的搁出去。茅盾写浴池，界线沿池岸画，池子以外不写。
  - 何时用：写光景、速写一类文章，怕写成「杂乱无章的流水账」时。
  - 怎么做：先定兴趣所在，据此圈定范围；再交代位置分明（池是圆的、五个人头构成半规形），使人「简直可以画一张图画」。
- **似乎 / 大概（专写光景的手法）**：写光景时只能根据看得见的外貌，推测人物里面的思想感觉，故用「似乎」「大概」。
  - 何时用：速写中写到他人的心理时。
  - 怎么做：去掉「似乎」「大概」，就成了「作者的眼光钻到人物里面去」，破坏全篇一致；小说可无所不知，但小说不是专写光景的文章。
- **抒写感情即记叙**：「抒写感情的文章大都是记叙文」，离开事物感情无从兴起；只要「把引起你感情的缘由和经过写出来」，读者自会感动。
  - 何时用：想表达快乐、痛苦等感情时。
  - 怎么做：不堆砌「快乐呀痛苦呀」；写外在事物与内心变化，如《收获》通体无「满足极了」却是最好的抒情文。
- **随笔与新鲜的意趣**：随笔是最自由的文章，形式无一定、题材随处可取，但「唯一条件在于『新鲜的意趣』」。
  - 何时用：写读书心得、日常见闻、感想时。
  - 怎么做：以作者自己作准，觉得新鲜且料想有一部分人也会新鲜才写；可作写作他种文章的基本练习。
- **风格**：每个成熟作者的特具风格；老舍的风格从「尽量利用口头语言」与「幽默趣味」显示，幽默的根柢是「心怀宽大」。
  - 何时用：阅读文章从「种种方面着眼」时，理会风格是一方面。
  - 怎么做：看字眼选择、语句调子是否纯粹口头语言，看是否「大处落墨」在气势声音上用功夫。

## 关键概念
- **接谈三法**：解决生字难语、划分词的三办法——凭自己的经验、查词典、请问别人；还要辨明最主要的词。
- **情境相生**：《收获》由愉快心情亲手做愉快工作，才写下充满快感的文章。
- **衬托**：作者说自己「聪明过分」「太聪明了」，正衬出父亲始终把儿子当孩子保护。
- **细腻由于精密**：「写得细腻由于看得精密」——写一个紫铜冷水龙头也如亲眼看见。
- **以一部分显示全体**：《整理好了的箱子》只写一夫一妇，「没有关系的」一概不叙，却能叫人感到纷扰空气。
- **热情两派**：一派内热外冷，一派内外俱热；巴金近后一派，热情奔放，「不很顾到节制和含蓄」。
- **文章从真实生活产生**：「有了充实的生活才有好文章」；《朋友》之好，正因从交游的真实生活里长出。
- **虚写点明心情**：作者从眼中看出的一语衬托，可作全篇点睛。

## 心智模型
- 当读一篇记人文时，把各段材料理解为围绕「主脑」的向心力——无关的写得再好也该删。
- 当想抒发强烈感情时，把「快乐/痛苦」字眼理解为无效符号，把「缘由与经过的记叙」理解为真正的抒情。
- 当写速写时，把目光理解为照相机：只记位置与外貌，用「似乎」留出推测的分寸，不钻进别人心里。
- 当遇到一个成熟作者时，把「风格」理解为这个人一言一动的标记，从字眼与调子去辨认，而非玄妙之物。

## 反模式
- **堆砌感情字眼**：连写一百个「快乐」「痛苦」，别人只知你在说这个词，无从感受，更说不上同感。
- **钻进人物心里写光景**：去掉「似乎」「大概」，便破坏专写光景的全篇一致——那是小说的便利法门，不是速写。
- **写流水账**：把种种光景全记下来，杂乱无章，叫人摸不着头脑；作者也无写这种账的必要。
- **写与人物性格无关的「开相」**：容貌、态度、服装若与思想行动无关，只是浪费笔墨；「豁达大度」一类评判语更不能算描写。
- **写文字游戏式的文章**：材料不从真实生活来，如学生空写《朋友说》《交友的益处》，无非教科书概念那一套。

## 文中实例
《背影》讲析：朱自清写父亲买橘子爬月台，仔细写他穿戴、走到铁道边、两手攀着上面、肥胖的身子向左微倾——这是实写，使读者宛如看见。作者本可以把「父亲不肯让自己去买橘子，仍把自己当小孩子」等深情都写出来，但他不写，只写「我的泪很快地流下来了」，因为读者自能领会，明白写出反而多余。后一回写背影消失在人群，也说「我的眼泪又来了」。全篇记父亲的话只四处，都极简单，却句句是深情流露。结尾评一句：通体干净，「即使一个『的』字、一个『了』字也是必须用才用」。

## 关键要点
1. 读散文先抓「主脑」与「主旨」，用它们统率全部材料，分清哪些该写、哪些一笔带过。
2. 记事写人以动作言行见性格，多用实写，少用评判；一语虚写可作点睛。
3. 写光景先画界线、交代位置，用「似乎」「大概」守住旁观的分寸。
4. 抒情靠记叙引起感情的缘由与经过，不靠堆砌「快乐」「痛苦」字眼。
5. 随笔以「新鲜的意趣」为唯一条件，是青年练习作文的最正当大道。
6. 阅读可从多方面着眼，理会作者风格是其中一方面。
