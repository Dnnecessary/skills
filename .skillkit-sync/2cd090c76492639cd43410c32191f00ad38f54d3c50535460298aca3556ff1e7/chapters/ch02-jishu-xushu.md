# Chapter 2: 记述与叙述

## Core Idea
记述写事物的光景（空间的、静的），叙述写事物的变化经过（时间的、动的）；叙述其实是许多记述的连续，二者的共同要诀是依顺序写、突出特色，并靠剪裁把"新的意味"传给读者。

## 框架与概念
- **记述与叙述的分别**：从光景着眼是记述，从变化着眼是叙述；前者是空间的、静的，后者是时间的、动的。
  - 何时用：动笔前判断自己要写的是事物的"一时状态"还是"变迁经过"。
  - 怎么做：用比喻记——记述文是静止的照片，叙述文是活动的电影；写人写面貌衣着一时的光景是记述，写一生变迁是叙述。
- **记述的顺序＝观察的顺序**：事物材料摆在面前，须先观察、把事物从森罗万象中提出、归纳分作几部分。
  - 何时用：写事物光景、安排记述文次序时。
  - 怎么做：平列无统属者（桃红柳绿、山高月小）任从哪方说起皆可；有统属关系者（房子、植物）须从全体看起顺次写各部分。
- **好记述文的两个条件**：着眼位次（依自然顺序把千头万绪分别述说，说花不说干）、着眼特点（重要部分详述，无特色处略带）。
  - 何时用：检验一篇记述文是否合格。
  - 怎么做：顺序不乱、特色明显；如写学者住宅应注重书斋，客室厨房从略。
- **叙述的顺序＝时间的顺序＋剪裁**：时间是叙述文的重要元素，但须从无限时间中切取与事情最有关系的一段。
  - 何时用：写事物变迁经过时。
  - 怎么做：从开始写到完毕，前后无关时间不必放入；对切取时间的各部分不平等看待，突出特色，无关特色材料越少越好。
- **题材的标准：新的意味**：平凡人人皆知的事物不能做记叙题材；新奇意味分两类——事物本身不平凡，或事物平凡而作者发现新意味。
  - 何时用：选材时判断什么值得写。
  - 怎么做：观察、体会、发掘平凡事物中蕴含的新意味；新意味是记叙文题材的生命，观察体会的修炼是基本功夫。
- **材料的判别与取舍**：新意味可归纳为新的知识、新的情味、新的教训三种；文章本身的意味是决定材料的标准。
  - 何时用：从题材所包含的事项中选取材料时。
  - 怎么做：第一步依意味选一群适宜材料；第二步把意味再分析，精选适切材料；微小事项运用得当也能成重要材料。
- **叙述的快慢（详略）**：详细写流动就慢，简略写流动就快；占中心的重要部分该慢，不重要的部分该快。
  - 何时用：安排各部分篇幅时。
  - 怎么做：快的叙述便于报告梗概（抽象概念），慢的叙述便于表现状况（具体特性）；把力量用在最重要的一段经过上。
- **叙述的倒错**：为显出特色、淘汰闲文而变动时间先后，是变格，必要时才可用。
  - 何时用：需追叙前因、或复杂事件需分头叙述时。
  - 怎么做：以最重要的一段为主，之前事项必要时追叙；关涉多方面时以一方面作主、其余作宾；胡乱倒错徒乱秩序。
- **过去的现在化**：叙述过去的事却用现在的说法，仿佛作者与事件同时。
  - 何时用：叙述久远往事、想增加读者兴味时。
  - 怎么做：省去"已""曾""了"避免重复；更重要的理由是让读者当作现在事件追求结果，满足其"参与发现"的自负心；旧小说"且听下回分解"即熟悉此心理。
- **观点的一致与移动**：作者的观点如照相机镜头可转动；在可能范围内须一致，但不要无意义地移动。
  - 何时用：记述景物、叙述多面事件时。
  - 怎么做：记述文把同类事项归并来写使每段观点统一；叙述复杂事件选定一方面为主、其余穿插进去。
- **日记 / 游记 / 随笔**：三种生活记述文体，各有其纲领与写法。
  - 何时用：写这几类文章时。
  - 怎么做：日记以时日为纲领、读者是自己、求简洁，功用是备查检、助修养、练习写作；游记以地域为纲领、读者是他人、须把作者行动与境地光景融合并持续流动；随笔写随时随地的片段，不拘结构与题目，从实际生活出发，是"文章上的速写"。

## 关键概念
- **记述文**：写事物在一时一地的光景、状态，空间、静止。
- **叙述文**：写事物的变迁、经过，时间、流动。
- **剪裁**：从无限的时间或材料中切取最有关系的一段、突出特色、删去闲文的功夫。
- **新的意味**：记叙文题材的生命，可由事物本身不平凡或平凡事物中被发掘。
- **知识 / 情味 / 教训**：记叙文给予读者的三种东西；记述文只有知识情味，叙述文三者兼具。
- **快的叙述与慢的叙述**：分别便于报告梗概与表现状况，中心部分宜慢。
- **倒错**：必要的追叙或分头叙述，以淘汰闲文、显出特色。
- **场面**：叙述文中一段连续时间和一个特定空间，犹之戏剧里的一幕。
- **过去的现在化**：用现在笔法写过去事件以增进读者兴味。

## 心智模型
- 把记述理解为"照片"、叙述理解为"电影"：叙述是许多记述的连续。
- 当写有统属关系的事物时，用"全体→各部分"的顺序；当写平列事物时，可任意起说。
- 当材料繁多时，把"文章本身的意味"当作取舍的尺子：意味不同，同一事物的材料取法就不同。
- 当叙述长过程时，把篇幅当资源——重要处慢写、次要处一笔带过，皆为显出特色。

## 反模式
- **平凡人人皆知的事物直接做题材**：令读者厌倦，毫无意义。
- **有统属关系却东说一句西说一句**：顺序乱、无秩序，别人看不明白。
- **平等看待时间各段、流水账式记录**：特色被淹没，无趣且不得要领。
- **胡乱倒错时间**：徒乱秩序，毫无效果；倒错只能是必要的变格。
- **游记死板地单独写境地光景**：流动随时停止，减少趣味；须把行动与光景打成一片。
- **随笔预定题目凭空立说**：失去随笔"发端于实际生活"的特质与新鲜味。

## 文中实例
写岳飞这一题材：《宋史》以历史的知识为主，教训、情味次之；《精忠传》以情味为主，教训、知识次之；《少年丛书》以教训为主，知识、情味次之。同一题材，意味不同，材料的判别取舍就完全不同——知识上重要的材料，在情味或教训上也许无用。这正说明"文章本身的意味是决定材料的标准"。

## 关键要点
1. 动笔先分清是记述（光景、静）还是叙述（经过、动），据以安排顺序。
2. 记述求顺序不乱、特色明显；叙述求时间顺序加剪裁，突出特色。
3. 选材以"新的意味"为生命，从平凡事物中观察体会出新鲜的意味。
4. 以文章意味（知识/情味/教训）为准判别取舍材料，微小事项也可用得其所。
5. 用快慢（详略）分配篇幅：中心重要处慢写，不重要处快写或略去。
6. 必要时才倒错、始终注意观点一致；叙述过去可用现在化以吸引读者。
7. 日记、游记、随笔各依其纲领与读者对象，核心都是剪裁与显出特色。
