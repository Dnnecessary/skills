# 速查表：叶圣陶、夏丏尊阅读写作决策指南

> 这不是术语表（见 glossary.md），而是"遇到写作/阅读问题时该怎么判断"的决策依据。每条都来自原书主张。

## 一、根本判断

| 情境 | 该怎么做 | 原书依据 |
|---|---|---|
| 要动笔写东西 | 先问"写给谁看、为什么写"，把它当作生活里的实际需要，不是为当文人 | 习作是发表意思情感的需要，是实际生活，不是假设游戏 |
| 写不好 | 问题多半在"说的"层面，即底子（世界观、人生观、语言习惯），不在写字 | "写得好就因为说得好"，底子好才是根本 |
| 读一篇文章 | 内容和形式两方面都探究，不可只领受内容 | 第一讲"文章面面观" |
| 说"这篇好/不好" | 必须说得出好在哪里、不好在哪里，不能只堆形容词 | 《认真阅读》 |

## 二、写作决策规则

**题材与材料**
- 选材标准 = 文章本身的"意味"。意味分三种：**新知识、新情味、新教训**。先定意味，再取舍材料（第十四讲）。
- 写"月"：天文学书取知识材料，诗歌取情味材料——同一题材，意味不同，材料完全不同。
- 微小事项也能成为重要材料："荆棘中的铜驼"表亡国，"镜中的白发"表衰老——运用适合即可，不在大小。

**人称与观点**
- 第一人称：写"我"亲历，长于直接经验与内心。
- 第二人称：把读者当"你"，拉近、便于呼告。
- 第三人称：写他人，可自由移动视点。
- 一条铁律：**观点要一致**；如需移动，须有清楚的转换交代（第十八讲）。

**叙述技巧**
- 快慢由内容的价值决定：重要的慢写、详写，次要的快写、略写（第十五讲）。
- 倒错（倒叙、插叙）服务于"使读者产生疑问—解答"的效果，不可为技巧而技巧（第十六讲）。
- "过去的现在化"：把往事写得像正在发生，增强现场感（第十七讲）。

**描写**
- 描写 = 记印象。景物描写要"我"在其中（有观察点、有感受），不是客观罗列（第三十三、三十四讲）。
- 人物描写抓"特征性的一两点"，不在面面俱到。
- 背景是为烘托人物与主题服务的，不是独立布景（第三十六讲）。

**说明与议论**
- 说明文重在"使人懂"，按事物的关系（异同、因果、处理法）组织（第四十八至五十二讲）。
- 议论文三件事：**主旨、立论与驳论、变装（隐蔽的议论）**（第六十七至六十九讲）。
- 三种推理：**演绎（一般到个别）、归纳（个别到一般）、辩证（正—反—合）**（第七十至七十二讲）。

**修改**
- "好文章是改出来的"——写完必改。
- 改的标准：**上口、入耳**（念几遍，不顺口的地方就是要改的地方）。
- 修改检查："通与不通"（意思是否连贯）、"准确·鲜明·生动"。

## 三、阅读决策规则

| 你要做的事 | 方法 | 出处 |
|---|---|---|
| 消除对文艺的隔膜 | 从自身经验出发：儿歌、民歌也能引发鉴赏，文艺鉴赏人人有份 | 《认真阅读》 |
| 提升鉴赏层级 | 从"被动感动、只看故事"进到"研究考察它为什么感动我"——着眼艺术手法 | 《认真阅读》 |
| 读懂文字背后 | "驱遣我们的想象"：文字是桥梁，要靠想象把文字化成具体的画面与感受 | 《驱遣我们的想象》 |
| 培养语感 | 训练语感——对词语的分寸、语气、声调的敏感，处处有用 | 《训练语感》 |
| 吸收语言 | 揣摩——反复玩味关键语句的所以然 | 《揣摩》 |
| 精读 | 三步骤：**通读全文 → 认识生字生语 → 解答教师所提示的问题** | 《精读的指导》 |
| 略读 | 五项指导：**版本、序目、参考书籍、阅读方法、问题** | 《略读的指导》 |
| 独立阅读 | "靠自己的力阅读"——认定目标，不依赖逐句讲解 | 《中学国文学习法》 |

## 四、快速信号（Tells & Smells）

- 一篇文章只有报告、没有作者自己的意见 → 读时要警觉：他有没有真正的主张？（第四讲）
- 只说"紧张极了/巧妙极了"这类形容词 → 鉴赏还停留在浅层（认真阅读）
- 情节荒诞、没有真切人生经验作骨子 → 不是真文艺，是"一派胡言"（认真阅读）
- 写文章只为发表、求名声 → "急于创作，最容易浮夸、失望；《文心》序"
- 只重思想、忽略语汇字句篇章声调 → 得到的思想是"浮光掠影"的变形（《文心》序）
- 下笔前不"想清楚" → 写出来的必然杂乱（《想清楚然后写》）

## 五、阈值与默认值

- 精读文章数量：宁精勿多——"取少数的文章来精读，学得文章学上的一切，才是经济的办法"（第一讲）。
- 每篇文章的探究项目：体制、语汇、文法、修辞、鉴赏批评、风格、章法布局——七项逐一留意。
- 读完一篇：至少复述"它讲了什么（内容）+ 它怎么讲的（形式）"。
